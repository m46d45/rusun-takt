# Panduan pelatihan — Rusun Takt

Simulasi **berjalan di browser** peserta (tanpa akun, tanpa instal). Bagikan URL aplikasi web; tiap peserta / kelompok membuka tab sendiri.

## Tujuan pembelajaran

Setelah sesi, peserta dapat:

1. Menjelaskan **parade of trades** (urutan 7 wagon) dan aturan satu zona = satu tim.
2. Membedakan **Push** vs **JIT** dan dampaknya pada **waste menunggu**.
3. Membaca ringkas **durasi, biaya tenaga, penalti, margin, waste %**.
4. Mendiskusikan mengapa “kirim semua tim lebih awal” belum tentu lebih hemat.

## Persiapan fasilitator (10 menit)

- Pastikan URL aplikasi terbuka di proyektor / laptop Anda.
- Set **Seed = 42** untuk seluruh kelas (hasil bisa dibandingkan).
- Mode default: **Workshop**.
- Siapkan 3 pertanyaan debrief (sudah muncul di app setelah bandingkan).

## Agenda 60 menit

| Menit | Aktivitas |
| --- | --- |
| 0–5 | Konteks: rusun 3 lantai, lean / takt, tujuan sesi |
| 5–10 | Buka **Istilah** + ringkas aturan (push, JIT, curing, waste) |
| 10–20 | Skenario **A** (Push · M1 · 1–6): Start → Selesaikan → amati waste |
| 20–30 | Skenario **B** (JIT · 7–7): Start → Selesaikan |
| 30–40 | Skenario **D** (Bandingkan Push vs JIT) atau tombol **Bandingkan Push vs JIT** |
| 40–55 | Diskusi temuan + unduh ringkasan (opsional) |
| 55–60 | Satu takeaway per kelompok |

## Agenda 90 menit (opsional)

Tambah skenario **C** (JIT · 3–3), lalu **Bandingkan kapasitas**, dan biarkan 1–2 kelompok mencoba mode **Lanjutan** (ubah start satu tim saja).

## Peran di kelas

- **Fasilitator:** jaga seed, waktu, dan pertanyaan diskusi — jangan “membocorkan” jawaban sebelum peserta melihat angka.
- **Peserta:** jalankan di browser sendiri; catat waste % dan margin.
- **Kelompok (3–5 orang):** satu laptop cukup; ganti skenario bersama.

## Apa yang diharapkan muncul (arahan, bukan kunci mutlak)

Dengan seed 42, skenario Push biasanya menunjukkan **waste menunggu** lebih tinggi daripada JIT pada kapasitas yang sama. JIT mengurangi hari dibayar sebelum zona siap. Kapasitas lebih cepat (3–3) memendekkan durasi, tetapi margin tetap bergantung waste & penalti.

Angka pasti bisa berubah jika seed / setup diubah — yang penting pola pembelajarannya.

## Checklist teknis

- [ ] Peserta hanya butuh browser modern (Chrome / Edge / Firefox / Safari).
- [ ] Tidak perlu login.
- [ ] Jika suara tidak terdengar: klik sekali di halaman (kebijakan autoplay browser).
- [ ] Unduh ringkasan = file `.txt` di perangkat peserta.

## Batasan model (sampaikan di awal)

Yang dihitung: upah tenaga saat di site (termasuk menunggu).  
Tidak dimodelkan: material, alat, headcount regu, mob/demob individu.
